# ResearchClip 0.1.0-rc.1 · Windows 预发布

面向科研人员的本地截图、图片标注与知识卡片工具。本次是公开测试候选，程序内版本为0.1.0；不代表完整MVP或正式发布验收通过。

## 下载与运行

- `ResearchClip_0.1.0_x64-setup.exe`：Windows x64当前用户NSIS安装包。
- `researchclip.exe`：可直接运行的Windows release程序；仍将配置和资料保存在应用数据目录，并非便携数据模式。
- `SHA256SUMS.txt`：下载校验值。两个程序均未签名，可能出现Windows安全提示。

需要WebView2。默认安装器在缺少运行时时下载引导，首次安装不保证离线。运行新版本前先保存并通过旧实例托盘退出；启动第二实例只会恢复已有窗口。

## 已有能力

Windows原生全屏/区域截图，区域和全屏独立快捷键，图片剪贴板及PNG保存；矩形、椭圆、箭头、画笔、文字标注与撤销重做，无损项目和原图分辨率导出；SQLite素材库、笔记、标签、搜索及Markdown原图导出；主题设置、系统托盘、单实例和退出保护。资料保留本地，无账号、上传或同步功能。

## 实际验证范围

TypeScript、ESLint、177项Vitest、87项Rust测试、cargo fmt、全部目标Clippy和Windows生产构建通过。原生编辑器、系统保存对话框、真实图片剪贴板、快捷键注册冲突、设置/托盘和安装/默认卸载有执行证据。

真实屏幕截图曾在Windows11主屏2560×1440、100%配置通过色块/裁切检查；不能外推到所有显示器。生成测试PNG的插件/持久化测试不作为屏幕读取证明。完整记录见仓库 `docs/qa/TEST_REPORT.md`，包括FAIL与未运行项。

## 已知问题与限制

1. **QA-001 / P2：**素材库测试退出时稳定出现两条0x80070578无效窗口句柄日志，套件整体FAIL；本次数据一致性断言通过，尚未查明根因。
2. **QA-002 / P2待归因：**托盘恢复曾超时，后续同代码复验通过，仍需物理托盘和Explorer重启验收。
3. 125/150/200%及混合DPI、负原点副屏像素、Windows10、生产版完整流程、1000卡/4K性能与长稳矩阵未完成。
4. macOS截图、回收站、标签改名/NFKC和Markdown合成图模式未实现；Markdown导出是原图与主笔记，带标注图片请用编辑器PNG导出。
5. 笔记草稿保留于当前进程；强制结束或断电不承诺未保存内容恢复。请确认保存完成后退出。

## 数据保护与卸载

素材库删除经过确认后是永久操作，当前没有回收站。安装/卸载检测到应用仍运行时中止，不强制结束它。默认卸载保留科研资料；用户主动勾选“删除应用数据”会删除资料。本次安装测试核对了8份既有核心文件hash不变，未在真实资料上试验删除数据选项。

建议先用非唯一副本资料试用，并按仓库人工清单反馈。该预发布不替代正式发布质量门槛。
