# v4.1.6 数学论文 Markdown

仅实现Step07，在现有源码保真编辑器、文件服务、图文块、EditorSession与撤销历史上增量开发。没有Markdown导出PDF、独立备份恢复或额外权限。SQLite12不变。

- 行内/块级KaTeX公式、实时输入预览，以及分式、矩阵、求和、积分、多行推导、极限模板。语法错误显示原文，可保存后继续修正。
- 定义、假设、引理、定理、推论、证明、例子、反例；可读的行首:::语法，未闭合或嵌套内容保留源码。
- 公式、定理、图、表自动编号，可按整篇/章节、环境共用/独立和起始值配置。稳定文内标签与标准Markdown链接组成交叉引用；重复/缺失标签有诊断。
- 编号是显示数据，重排后重算，切换四种模式不改写未编辑的正文。标签跟随支持的对象整体拖动；旧图文稿继续使用私有格式版本1。
- 论文工具折叠与窄窗换行，长公式局部滚动。指南增加第24章、8项练习与数学论文路线。

语法、边界和安全选项见[技术记录](architecture/MATH_PAPER_STEP07.md)，操作见[使用指南](USER_GUIDE.md)，实际结果见[Step07验收](qa/MARKDOWN_STEP07.md)。本轮612项前端、237项Rust、53组Windows原生、45组浏览器、2组记事本与4组安装验证通过；7项既有Rust用例忽略，物理IME/多DPI/先前锁屏OLE仍需人工验收。附件包含此前35版1210个原文件及本版应用，发布与匿名下载结果见[发布检查](qa/RELEASE-4.1.6.md)。
