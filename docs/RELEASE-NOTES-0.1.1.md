# ResearchClip v0.1.1 · Windows 桌面贴图预发布

程序内版本同步为 0.1.1，新增类似 Snipaste 的桌面截图贴图。

## 下载与运行

- ResearchClip-v0.1.1-windows-x64.exe：Windows x64 程序。
- SHA256SUMS.txt：程序校验值。
- SOURCE.txt：准确源码提交与交付范围。

保存资料并彻底退出旧实例后运行 EXE；需要 WebView2，程序未签名。此次没有新的 NSIS 安装包。程序继续使用应用专属数据目录，不是便携资料模式；数据库迁移和用户原图没有改动。

## 新增功能

1. 截图完成区和图片编辑器均可点击“贴图”；编辑器使用包含标注的原分辨率合成图。
2. 真正独立的无系统标题栏置顶窗口，可同时打开多张，拖动移动、滚轮等比缩放。
3. 右键菜单复制图片、另存为 PNG、调整不透明度（20%–100%）、恢复位置、关闭贴图。
4. 主工具栏图钉按钮可恢复屏幕外贴图。隐藏主窗口到托盘保留贴图，取消退出保留，批准退出后统一销毁。
5. 图片快照独立于主截图缓存，最多 8 张及 256 MiB 图像预算；贴图窗口只可操作自身资源，不开放任意文件系统访问。

已有截图、五类标注、无损项目、SQLite素材库、科研笔记、搜索及Markdown图文/分栏功能保留。

## 检查与限制

贴图开发阶段实际通过 220 项前端、102 项 Rust、13 组 Windows 原生贴图和 6 组原有编辑器回归。改为 0.1.1 后的发布检查另见[发布核对](qa/RELEASE-0.1.1.md)，贴图范围及人工步骤见[贴图验收](PINS-VALIDATION.md)。

原生自动化运行隔离 debug 应用与受控 PNG，不能替代真实屏幕捕获、完整高/混合 DPI、多屏、长期堆/显存或生产版端到端人工验收。历史窗口退出句柄错误及托盘恢复超时仍未全面关闭。macOS 未验收，当前原生透明度仅支持 Windows；普通置顶不承诺覆盖安全桌面/独占全屏模式。贴图为会话功能，退出后不自动恢复。

源码遵守 .gitignore；本地构建缓存、工具链、测试截图、浏览器会话及数据库不上传。旧 Release 保留。本次为预发布，不宣称完整正式版质量认证。
