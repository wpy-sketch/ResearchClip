# ResearchClip v2.0.0 · 清晰工作区与分级使用指南

- 收敛深浅色主题、柔和边界与圆角，优化侧栏、工具栏、卡片和窗口缩小时的排布。
- 使用指南14章、19幅离线图示；支持章节/小节/详细步骤三级目录、展开收起、标题和正文搜索、阅读位置提示与返回目录。
- 每章补充开始前、操作步骤、完成检查和失败处理；保存到素材库、可编辑标注、PNG及Markdown清晰区分。
- 保持SQLite schema5、不可变原图和原有业务管线；没有新增依赖。WebDAV仅保留M1设计提案，尚无可用同步功能。

本版继续附带原兼容的 **ResearchClip-WebClipper-v1.0.2-windows-x64.zip**，包含MV3扩展、Native Messaging Host与安装说明；扩展版本及ID不变。可选MathOCR安装工具仍为v1.0.4，不捆绑模型或Python运行时。公式输出可能错误，必须人工校对。
