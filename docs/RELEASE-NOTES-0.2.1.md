# ResearchClip v0.2.1

本地 Windows 科研截图与 Markdown 工作区更新，普通 Release（非预发布）。

- **项目分类**：素材管理侧栏直接切换项目、全部素材与未分类；图片数量可见，窄窗口使用分类选择器。
- **离线数学排版**：`$...$` 行内和 `$$...$$` 独立公式，支持上下标、分式、求和积分、矩阵、希腊字母及多行公式。默认实时预览，仍可切换完整预览。
- **源码与安全**：标准 UTF-8 `.md` 保留 LaTeX 源文；错误明确显示，不自动猜测修正；拒绝公式链接/HTML及外部资源，无上传、CDN或模型。复杂 OCR 公式识别不在范围内。
- **其他应用**：先保存，再通过 Windows“打开方式”选择已安装的 Markdown 应用；不修改系统默认关联。外部改动后需重新打开或另存，避免覆盖。
- **图文指南**：任务分组、关键步骤与实际受控界面截图。现有截图、标注、分栏、模板、SQLite v3数据契约保留。

使用方式：从左侧项目分类浏览素材；新建/打开 Markdown，在源文输入公式；通过面板右上角“使用其他应用打开”按钮交给其他编辑器。详见 [使用指南](USER_GUIDE.md) 与 [实际验收](qa/RELEASE-0.2.1.md)。

Windows x64 EXE 未签名，需要 WebView2。先保存并退出旧版本，保留完整科研资料备份。此版本没有数据库迁移，旧库不清空。完整硬件/安装验收及 Obsidian/Typora/VS Code 逐个交互仍须人工执行；普通 Release 状态不表示这些未运行项已通过。
