# ResearchClip v0.1.5

Windows x64 Markdown 模板与文档大纲更新，按用户要求发布为非预发布版本。

- 内置空白、论文精读、数学定理推导、科研实验记录模板，自定义新文档名称。
- 保存当前文档为独立模板，复制受管图片，重启后可重新加载；支持重命名与确认删除，同名不覆盖。
- 自动 H1–H6 大纲、源文定位与预览跳转、显示/隐藏；代码块里的标题不会误识别。
- 沿用原有 `.md`、assets、保存/另存为、图文排序和未保存确认，不修改原图或 SQLite schema。
- 未打开文档时保持原工作区全宽；图文模式的目录导航只打开预览，不转换内容块。

使用：顶部“模板”选择类型并创建；右侧“显示大纲”导航，“保存为模板”创建可复用副本。模板选择对话框可管理自定义模板。删除后文件留在配置目录 templates-v1/deleted-* 中，不再显示在模板列表，可关闭应用后手动恢复或归档。

自定义模板最多100个、名称80字符，每份沿用2 MiB正文/32图/128 MiB资源限制。图片仅复制受管相对资源，外部图片不联网加载。模板和导出文档均使用普通 Markdown；无需专有正文格式。

真实测试、首轮失败修复、未执行项目与人工清单见 [0.1.5 验收](qa/RELEASE-0.1.5.md)。EXE 未签名，需要 WebView2；本次没有新 NSIS。完整硬件矩阵、长稳、macOS 及历史 QA-001/QA-002 尚未关闭。请先保存并退出旧实例，再运行新版本。
