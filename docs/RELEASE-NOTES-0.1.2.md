# ResearchClip v0.1.2 · 界面与主题更新

本版参考 Google 应用和 Material 3 的布局、色彩角色，优化科研截图与知识整理工作区。GitHub Release 按用户要求不再标记为预发布，程序内版本为 0.1.2。

## 更新

- 深色采用中性炭灰、柔和蓝色强调；浅色采用蓝灰背景、白色内容区和蓝色主操作。保留深色、浅色、跟随系统及用户字体设置。
- 左侧新增醒目的“新建截图”，导航采用圆角选中状态，明确“本地工作区”。
- 顶部搜索单独成行；第二行分组放置 Markdown 操作与网格/列表切换，窄窗口用带提示的图标按钮保留全部入口。
- 主内容区、截图面板、素材卡、设置与弹窗统一圆角、边界、间距和焦点样式。
- 截图、标注、桌面贴图、Markdown 动态分栏、SQLite 和笔记保存流程沿用，不改变用户数据或数据库迁移。

参考 [Material 3 色彩角色](https://m3.material.io/styles/color/the-color-system) 和[顶部应用栏](https://m3.material.io/components/app-bars/)。保留 ResearchClip 品牌，不使用 Google 标识、在线字体或新 UI 框架。

## 下载与运行

下载 ResearchClip-v0.1.2-windows-x64.exe，先保存资料并彻底退出旧实例，再运行新版。需要 Windows x64 和 WebView2；程序未签名。另附 SHA256SUMS.txt 和 SOURCE.txt，记录校验值及准确源码提交。本次提供直接运行 EXE，无新 NSIS 安装器。

源码、配置、两个锁文件及文档一并上传，旧 Release 保留；工具链、缓存、测试图片、浏览器会话及用户资料不上传。
