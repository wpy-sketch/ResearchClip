# ResearchClip v4.1.9

Step10在原工作区增加只读PDF标签：从系统文件框导入本地副本，连续单/双列页面，适宽/适页与自定义缩放，90度旋转，目录、懒加载缩略图、文本选择与复制、逐页全文搜索、页码跳转。多个PDF与Markdown独立会话并排，隐藏恢复与窗口缩放复用原布局系统。

SQLite15只存阅读位置与摘要/乐观版本，原有截图、Markdown和文献不迁走；001–014迁移不改。版本升级前执行原有完整性校验和一致快照，失败回滚。旧版拒写新库，升级前保存并退出旧实例。

PDF.js固定6.4.299，本地同版本Worker与必要解码资源。不执行PDF脚本、附件或表单动作。加密密码只在会话中使用，受限复制、损坏文件、超预算和取消都有明确状态。单文件128MiB、活跃输入合计256MiB、3会话、2000页；按视口绘制并限定Canvas预算。内部解析堆不能承诺绝对硬上限，复杂超大图像可能不完整，详见指南27.7。

新增6个主窗口限定IPC，没有通用文件、Shell或Agent权限。图标沿用原创多色科研烧瓶；PDF工具条使用明暗主题与焦点样式，指南增加第27章、10项练习与3幅实际Windows图，合计27章177练习44图。

全部此前38版2011份原附件字节继续提供，目标279附件；同名历史校验文件放各版Metadata.zip，原223运输卷沿用，不用链接替代附件。安装器未签名，使用前核对SHA256。当前正式发布与最终逐项下载状态以[发布检查](qa/RELEASE-4.1.9.md)为准；技术、测试、修改文件与人工边界见[Step10报告](qa/PDF_READER_STEP10.md)。

本版没有Markdown导出PDF、独立备份恢复、Zotero连接器、PDF截图批注或私有手写；后续功能只按用户明确授权的阶段实施。
