# ResearchClip v4.2.4

PDF与Markdown双向定位：直接点击文献摘录图片或稳定来源链接返回对应附件、页码和原始页面区域；每次重新核对内容哈希，保留现有旋转/缩放并显示约8秒临时高亮。文件被替换、页码或几何不匹配时明确拒绝跳转，不根据同名文件或页面偏移猜测来源。

PDF新增「笔记与来源」：按当前截图/文字选区查找相交位置引用，分别列出已打开草稿与磁盘索引。索引复用现有后台worker、源文SHA和事务，外部修改及缺失文件明确提示；从结果打开后按稳定链接重新定位，不用旧偏移覆盖草稿。

从PDF.js真实文字选区创建可读Markdown引用与稳定位置链接，保存exact文本锚点和多行矩形。插入当前光标、撤销重做、保存和新建确认沿用现有文档服务；旧OCR默认插入规则保持。两篇文献可在一份笔记中分别引用。受管只读副本使原始PDF改名/搬移后仍可阅读，内容相同复用标签，内容变化保留独立身份；不修改Zotero PDF。

来源信息显示文献标题、显示页码和已有Zotero库/item/attachment关联。笔记查询面板有界滚动、控件自然换行；展开面板保留文字选择。图标优化为圆角叠页、裁切标记和双向箭头，沿用四种明亮色。指南30章217练习59幅离线图，增加双向定位与文字来源操作说明。

SQLite18只增加PDF位置派生边索引，001–017不改；事务升级前沿用一致快照与验证，未来版本拒写，旧程序不能写新库。无新增或升级依赖、第二正文存储或全局ID系统。见[设计](architecture/PDF_BIDIRECTIONAL_STEP13.md)、[实际验收](qa/RELEASE-4.2.4.md)、[使用指南](USER_GUIDE.md)及[下载组件](RELEASE-COMPONENTS.md)。

本版继承此前43个Release的3466项原附件，309个最终附件包含当前安装包、便携包、离线指南及全部原有伴侣组件。安装器未签名；外部可选模型/运行时按原组件说明配置。正式发布及匿名下载完整性以发布回执为准。
