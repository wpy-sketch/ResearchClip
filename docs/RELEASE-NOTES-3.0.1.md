# ResearchClip v3.0.1

Windows x64正式版本，保留兼容的WebClipper v1.0.2插件附件。正式版本标识不代表所有Windows硬件、应用或服务商已经验收。

## 智能窗口截图

在截图素材页点击「窗口截图」，移动鼠标核对窗口标题、蓝色边界和物理像素尺寸；Tab/Shift+Tab切换候选，单击捕获，Esc取消。普通窗口图像使用Windows Graphics Capture获取，复用现有复制、PNG系统保存、素材库与Konva编辑器。

不使用桌面区域裁剪冒充无遮挡窗口截图。选择层无边框、置顶，隔离权限仅允许本次选窗；原生句柄不跨WebView。最小化、自身窗口、受保护内容不支持；窗口移动/缩放/关闭或显示器配置变化会明确提示重新选择。

## 可靠性与帮助

本机实测WGC在Close/Release后仍逐次保留ALPC连接，因此采用同一EXE的短生命周期本地捕获worker：不初始化Tauri、不读取数据库，私有管道、有界PNG、Windows Job资源限制、超时与取消回收。无新增运行时依赖、无后台监听端口，无原图或SQLite格式变更。

截图工具提供清晰的模式入口；选择提示采用克制蓝色边界与对比清楚的提示条。指南第2章增加开始前、操作、完成核对、遮挡与失败恢复，保持14章与可展开三级/四级目录，22幅离线图片/示意均标明来源性质。

## 使用与限制

保存并退出旧实例，再运行EXE或NSIS安装包；需要WebView2。产物未签名，下载后核对SHA256。浏览器插件保留原ID，按[插件安装说明](../browser-extension/README.md)加载。本版没有改变插件协议或WebDAV服务兼容性。

WGC路径需要Windows 10 1903或以上及可用D3D11硬件；本轮实际环境为Windows 11。普通窗口部分遮挡、负坐标屏幕、取消与资源释放的实际结果见[验收报告](qa/RELEASE-3.0.1.md)。125%/150%混合DPI、跨屏窗口、提权/安全桌面、HDR、远程桌面、全屏游戏、DRM及macOS仍需独立验收；不绕过系统保护，不保证所有应用内容可用。

旧QA-001/002/008记录和公式OCR误识别限制保留；真实坚果云认证/安全条件兼容性仍未验收。完整操作见[图文指南](USER_GUIDE.md)和[窗口捕获设计](WINDOW-CAPTURE.md)。不包含PDF导出、独立全库备份恢复、云OCR或自动同步。
