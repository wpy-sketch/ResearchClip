# ResearchClip v0.1.4

Windows x64 高级标注更新，按用户要求发布为非预发布版本。

- 马赛克：拖动矩形选区，以原图像素块做真实像素化，强度 2–64（默认 12）。
- 局部模糊：矩形选区使用 Konva StackBlur，半径 1–64 原图像素（默认 8）。
- 自动编号：点击创建圆形编号，数值从当前剩余对象最大值加一开始；可改颜色、大小、数字，删除不重排其他编号。
- 三种对象均支持既有选择、移动、调整大小、删除、撤销/重做、项目 JSON 和素材库保存/重新编辑。
- 原图始终保留。滤镜处理原图并置于矢量标注下方，重叠滤镜由后一个区域覆盖；PNG、图片剪贴板、桌面贴图、Markdown 合成图和编辑器 OCR 共享导出管线。

请选择工具后在图片上拖动或点击；切回“选择”移动对象、拖动手柄调整尺寸，在高级标注属性栏调整强度/编号大小或数值。PNG 输出原图分辨率，不包含手柄；可编辑项目仍携带原图。

标注 schemaVersion 仍为 1，新增类型由前后端共同校验；旧文件可打开，新类型需要 0.1.4 或更新版本，旧程序会拒绝不支持的类型，不要用旧版重新保存。SQLite schema 不变，不迁移或重置用户资料。总滤镜有效区域限制为 16,777,216 像素（重叠累加），防止无界临时画布；超出时保留此前编辑并报错。

实际检查、像素证据、已知限制及 Windows 人工步骤见 [0.1.4 验收](qa/RELEASE-0.1.4.md)。完整 DPI/多屏、长稳、大图性能和 macOS 未全面验收。EXE 未签名，需要 WebView2，本次无新的 NSIS 安装包。请先保存并退出旧实例，再启动新程序。
