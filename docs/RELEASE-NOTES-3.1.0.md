# ResearchClip v3.1.0

Windows x64正式版本，保留原版兼容WebClipper v1.0.2插件与可选MathOCR安装脚本。正式版本标识不代表所有硬件或WebDAV服务商已经验收。

## WebDAV设置修复

- 保存连接后直接确认本机配置与系统凭据；状态轮询不再占用所有操作按钮。过期轮询不会覆盖保存回执。
- 停止请求可在启动回执等待期间发出，后端取消不等待配置锁；启动与冲突处理不阻塞主UI线程。
- 连接、账号、密码或同步范围修改后先保存再测试；更换连接需重新输入凭据。Windows凭据失效明确提示，失败时保留输入供修复。
- 字段就近校验、保存成功提示、按钮不可用原因与读取重试。未开始时停止按钮灰色属于正常状态，安全探针和范围确认仍是必要步骤。

## 布局与指南

设置表单采用柔和分组、清楚的主保存按钮与可读状态提示，适配深浅主题和窄窗口。指南增加「保存没有反应」逐步排错、按钮条件表和两张Windows原生隔离测试截图，共23幅离线图示。截图中的本机地址仅为测试，不应作为用户的服务器地址照填。

## 升级与验证

先保存草稿并退出旧实例，再运行EXE或NSIS安装包。需要WebView2；程序未签名，请核对SHA256。不更改SQLite schema6、Annotation schema1、原图、既有文件或安全权限，不新增依赖。

Windows原生本机保存/系统凭据修复/停止/重启与隔离故障注入分别记录，见[验收报告](qa/RELEASE-3.1.0.md)。坚果云 `https://dav.jianguoyun.com/dav/ResearchClip/` 的真实账号认证仍未验收，请在本机安全输入应用授权密码完成探针；不关闭TLS校验，不绕过不可靠条件写入。125%/150%混合DPI、完整跨应用及macOS矩阵仍需独立验证。旧QA-001/002/008与公式OCR准确性限制保留。
