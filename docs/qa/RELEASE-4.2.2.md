## 人工验收与边界

1. 安装后用有权限的混合竖/横版PDF，检查适合宽度、适合页面、双页、旋转与手动缩放；拖动面板和窗口，核对页面比例及位置。
2. 从Zotero选择已下载附件，在设置选择ResearchClip程序作为外部阅读器；按指南第28章启用本机API并核对库范围、来源和重复打开行为。
3. 等待查询时取消，检查提示、候选与已保存来源；API不可用时继续阅读普通PDF。
4. 保存Markdown草稿、关闭并重启，核对旧截图、相对图片路径、阅读位置和工作区。
