## 失败记录与限制

前期原生用例暴露HTML拖动不重排、后端命令可用性未同步、隐藏面板滚动/页码竞态，均保留失败日志并修复后重跑。后续测试脚本修正关闭标签后的过期locator、实际预览类名及精确标签匹配。一次前端整合检查先于第29章落盘执行，3项指南数量检查失败；补齐指南后重跑。发布基础设施使用单文件测试入口；unittest discover未正确发现带连字符文件名，未把该次无用例执行计作通过。

7项历史Rust忽略用例不是通过。真实Zotero窗口输入此前GetCursorPos被拒绝，用户已要求保留人工验收，本轮不重试；只读接口隔离练习不代表该UI链路通过。模拟DPR1/2、CSS80/125%不替代真实高DPI、多屏、触控、旧WebView2或长期大文件内存验收。PDF.js整体解码堆不是OS硬内存隔离；扫描原文件缺失的细节不能恢复。

v4.2.2较长核对区间两项来源未明新增资料的原FAIL与文件保留，不自动归为测试文件、不清理或恢复。本版默认资料只读核对独立记录，不能覆盖此前事实。

## Windows人工验收

1. 退出旧实例、安装新版本，核对旧截图/Markdown和工作区；真实资料升级只在用户计划升级时进行，不用测试程序重置真实库。
2. 按第29章对实际论文公式、表格、插图使用144/216/288 DPI；不同物理显示缩放、跨屏及旋转后核对矩形与清晰度，工具栏不进入图片。
3. 连续两张及跨页摘录，选择真实本地文献；无来源时留空。标注后保存，核对原始截图及PDF未改写。
4. 在Markdown中间插入，注释写公式/列表，整体拖动并撤销重做；保存.md后用普通编辑器检查相对assets与可读源码。
5. 关闭/重启，重开.md并返回PDF来源；移走或损坏练习PDF时应明确失败并保留笔记，勿以真实唯一副本演练。
6. 用户方便时按第28章完成真实Zotero外部阅读器、个人/群组来源和API设置；可回退内部阅读器。无API也应可读普通PDF。
