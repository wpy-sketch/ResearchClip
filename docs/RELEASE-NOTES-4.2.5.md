# ResearchClip v4.2.5

只读Zotero标准批注：在PDF工具栏打开「Zotero批注」，选择已确认的资料库与附件来源，主动读取高亮、下划线、文字便签、文本和区域批注。原annotation key、library ID、颜色、文字与位置保留；文字及颜色筛选同步作用于列表和图层，点击定位并临时高亮，旋转、跨页、CropBox与UserUnit沿用真实PDF.js变换。

本机Local API仅GET，不访问Zotero SQLite，不写入批注、不修改原PDF。缓存按Zotero实例、库、附件及PDF内容哈希隔离，断线、403、取消或分页版本变化保留上一完整快照并显示时间；来源冲突停止叠加，重启后可读缓存。在线刷新仍要求已授权原件。ink和未支持位置保留诊断，不转换为ResearchClip私有手写。

列表和工具条自然换行、面板内滚动，四种颜色的新图标以文献页、摘录框和确认标记组成。指南按顺序扩展到31章、229项练习、62幅离线图，新增读取、筛选、重连、授权与人工核对步骤。

SQLite18→19仅追加派生批注缓存，沿用升级前校验、一致快照和事务；001–018原迁移不改，未知未来版本拒写。无新增或升级依赖。设计见[Step14](architecture/ZOTERO_ANNOTATIONS_STEP14.md)，测试和人工边界见[本版验收](qa/RELEASE-4.2.5.md)，操作见[指南第31章](USER_GUIDE.md)。

本版计划完整继承此前44个Release的3775项原附件，最终315附件包含当前NSIS、便携ZIP、离线指南及全部原有组件；正式状态与匿名下载完整性以发布回执为准。安装器未签名，可选模型和运行时沿用[组件说明](RELEASE-COMPONENTS.md)。

实际Zotero10.0.6只读接口探测与隔离HTTP夹具测试分别记录；真实Zotero窗口多类型文献、物理混合DPI、其他系统和长期内存仍需人工验收。没有标准批注写回、私有手写转换、Markdown导出PDF或独立备份/恢复系统。
