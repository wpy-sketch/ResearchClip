# ResearchClip v1.0.0 正式版

Windows 本地科研截图与 Markdown 工作区。正式 Release，不标记预发布。

## 本次改进

- 素材页压缩截图空状态、重复说明与未选择的批量按钮，让首屏优先显示图片；网格/列表、深浅色和窄窗沿用同一资料与主题。
- 图文指南保留14节，增加采集→整理→写作阅读路线、章节高亮和搜索清除。
- 新增8张实际应用界面图，合计10张离线图示；点击或键盘Enter放大，Esc关闭。图片使用独立示例资料，曲线不是科学实验结果。
- 补充各工具操作步骤、保存方式差别、项目/多选范围、Markdown/公式例子、快捷键、敏感图像分享、备份和排错。
- SQLite保持schema v3，既有001/002/003迁移、标注JSON、原图路径和用户配置保留；不新增依赖、云服务或权限。

## 使用

先保存并退出旧实例，再启动新程序。截图后点击「存入素材库」；编辑后「保存到素材库」保留可编辑标注；文档Ctrl+S保存 `.md` 与 `assets`。完整操作见[图文使用指南](USER_GUIDE.md)。

Windows x64，需要WebView2；EXE和NSIS安装包未签名。完整实际命令、失败/受阻项和人工检查见[验收报告](qa/RELEASE-1.0.0.md)。正式版本标识不表示未执行的硬件、macOS或第三方软件矩阵通过。实际原生验收环境已在独立目录完成安装、运行中拒绝覆盖/卸载、默认卸载及资料摘要保留检查；没有启动生产程序写入真实科研资料。
