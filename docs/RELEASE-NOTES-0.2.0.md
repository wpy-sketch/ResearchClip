# ResearchClip v0.2.0

科研项目与批量素材整理，继续使用本地Tauri/Rust/SQLite，不引入云服务或账号。

## 主要变化

- 新建/重命名/确认删除空项目；每图一个项目，标签跨项目共享。
- 全部素材、未分类和项目筛选；项目中浏览截图与已登记Markdown，显示两类数量。
- Ctrl/Shift多选、跨页筛选全选、批量标签合并、移动、收藏/取消收藏、导出和数量明确的删除确认。
- SQLite v3备份迁移、整批版本校验/事务回滚和持久文件清理；不修改原图路径、ID、笔记、标注或来源。
- 紧凑项目操作条和批量工具区；14节完整指南按任务分组，可搜索章节，阅读区优化留白与段落层次。

## 操作与边界

[完整使用指南](USER_GUIDE.md)第5节说明项目和批量操作。第一版只删除空项目，非空项目请先移出资料，不提供隐式删除所有内容。批量删除会永久删除受管图片与关联资料，须明确确认数量；外部原图、Markdown和assets保留。

全选最多5000张，超限要求缩小范围，绝不只选前几项。原有Markdown批量导出每次100张与资源上限保持。Markdown需先保存或打开才能登记项目；应用内改名保留关联，外部移动需重新打开登记。升级前自动备份，旧版不能写v3，请勿删库或降级覆盖。

Windows x64 EXE需要WebView2、未签名；先保存退出旧实例。普通Release不代表所有人工/硬件验收通过。本轮无新NSIS，安装卸载、高DPI/多屏、长稳和macOS未完成；历史托盘/退出问题继续跟踪。

真实检查与失败修复详见[0.2.0验收](qa/RELEASE-0.2.0.md)。
