## 1. 定位与用户

ResearchClip 是面向科研人员的本地桌面截图与知识管理工具。首发覆盖读论文、观察实验/仿真结果、记录网页或软件界面时的图像采集与解释。用户无需账号，离线完成日常工作，资料留在自己的电脑。

典型任务：截取一张论文图表 → 用箭头和文字指出结论 → 写观察笔记 → 加上实验/主题标签 → 之后搜索找回 → 导出到 Markdown 研究记录。

## 3. 关键流程与交互规则

### 采集

- 主界面和托盘可触发截图，快捷键在主窗口隐藏时仍可用。
- 默认快捷键候选：区域 Ctrl+Shift+2、全屏 Ctrl+Shift+1；以实际可注册结果为准，允许修改，不抢占冲突组合。
- 快捷键的目标默认是鼠标所在显示器；读不到位置则选择主屏并在UI说明。设置可改为固定显示器；显示器拔出后回退并提示。
- 隐藏应用自己的窗口后读取冻结帧，再显示覆盖层。正在截图时的重复触发返回“正在截图”，不启动另一会话。
- 区域触发后仅在目标显示器显示覆盖层，选区只允许在该屏内完成，拖动越界被裁到该屏边界；不偷偷拼接其他屏幕。空选区/Esc不创建卡片或文件。
- 只有PNG落盘和数据库提交成功才显示“已保存”；随后打开该卡片进入编辑。失败恢复原窗口/托盘状态，显示可理解的原因。

### 标注与保存

原图一直保留。图元位置使用原图物理像素，缩放只影响视口。一次自由画笔笔画、拖动、文本提交或样式修改分别计为一个撤销操作；撤销后产生新操作清除 redo 分支。切换选中对象和视口操作不进入图元编辑历史。

首发使用显式“保存”与 Ctrl+S，笔记和标注独立显示脏状态。离开卡片、关闭/退出或启动另一截图前有未保存内容时提供保存/放弃/取消；默认取消。保存失败保留编辑内容。撤销回到当前已保存快照时恢复干净状态；历史容量不足时先丢弃最老记录并告知，不保存整张图像到历史。

导出基于一个已保存且固定revision的内容快照；有未保存内容时先保存或取消。导出不会更改原图和编辑文档。文本使用本机字体；macOS字体一致性在适配阶段验证。

### 整理与搜索

一卡对应一张原图、一个标注文档和至多一个笔记。笔记是Markdown源码编辑，首发不要求富文本或HTML预览。标签名trim + NFKC + ASCII小写后建立唯一键，显示名保留用户输入；不合并简繁中文或做语义推断。

搜索匹配卡片标题、笔记正文、关联标签的字面子串；ASCII不区分大小写，中文按字面匹配。空关键词展示全部正常卡片，%、_和反斜杠视为普通字符；多标签筛选采用AND。查询与筛选可以组合，采用稳定分页，结果不重复。复杂分词和相关性排名放到后续。

### 托盘与设置

托盘菜单可打开主窗口、触发全屏/区域截图、退出。默认关闭主窗口真正退出；用户可明确启用“关闭到托盘”。托盘创建失败时保留可见主窗口和退出入口。用户改快捷键时采用“新组合注册成功→持久化→注销旧组合”，任一步失败恢复旧配置。

设置仅包括本表范围，不允许首发在UI中移动数据目录。真正退出前处理脏编辑、取消捕获、释放原生资源并注销热键。第二次启动应激活已有实例，避免同时写同一工作区和重复注册热键。

## 4. 数据、质量与限制

- 原图PNG无损保存，元数据与笔记/标注存SQLite，缩略图可重新生成；不使用localStorage保存科研内容。
- 可正常离线运行；无账号、上传或遥测。文件缺失、数据库损坏/版本过高应明确报告，不自动抹去用户资料。
- 首发验证SDR和单屏最高4K；HDR、受保护内容、锁屏/安全桌面和远程会话不作支持承诺。无法取得帧时报告失败，不返回占位图或宣称成功。
- 初始资源上限：单次冻结图像不超过16,777,216像素，单文档最多2,000图元、总画笔点数100,000、标注JSON 8 MiB、单笔记1 MiB。超过上限明确拒绝并保留原状态；上限调整需有内存/性能证据。
- 回收站资料不会自动清空；首次版本不给用户导出路径中的已有文件写入权限。导出到用户选择位置中的新子目录，冲突时失败或选择新名字。
- 搜索性能、截图延迟、DPI误差等数值目标及测量方法以ROADMAP为准；目标尚未达成时不能写成实测结果。

## 5. 首发完成的定义

F01–F08均有真实Windows运行证据，且通过M2–M5阶段门槛。连续完成“快捷键截图→五种标注→撤销/重做→保存重启→笔记/标签→检索→PNG/Markdown导出”的完整流程，原图哈希不变，导出在应用外可读。

M1骨架和本轮文档完成不等于MVP完成。截图权限/DPI硬件矩阵、迁移与恢复、托盘生命周期、导出失败路径存在未解决问题时，按ROADMAP报告未通过项。

用户显式选择链接、选中文字、主要正文或页面图片，预览/改标题/选项目/保存/重试。剪藏是标准Markdown项目文档，不是截图笔记副本；扩展和Host不能操作SQLite。离线提取与匿名可访问图片复制不绕过访问控制，失败保留来源，取消不删除已提交资料。[安装与限制](../browser-extension/README.md)。
