# ResearchClip v1.0.1 · 浏览器滚动长截图

在现有Windows截图工作流上新增滚动长截图MVP。支持显式选择窗口和单屏正文区域、手动滚动拼接，以及Chrome/Edge普通网页的限定自动滚动；不承诺所有应用和网页。

## 使用步骤

1. 在网页起点点击「滚动长截图」，明确选窗口并框选正文，排除地址栏、滚动条、固定底栏和悬浮控件。
2. 先用手动模式，每次滚动约半屏后点击「采集下一段」；或对兼容浏览器启用自动模式。请保持目标可见、鼠标在选区内、无修饰键按下。
3. 「停止」生成已有部分，「取消」释放本次临时图像。完成后核对接缝/末尾，再保存PNG、存入素材库或标注。

独立StitchingEngine匹配垂直重叠，只接入新增底部。重复或无法可靠拼接时不会完整叠放各帧；自动模式遇失焦、遮挡或鼠标移出即暂停，提供手动回退。沿用已有原图不可变、系统文件对话框和禁止自动覆盖策略，schema v3和既有迁移不变，无新增依赖。

## 限制与检查

每次同时受64帧、180秒、30,000像素高和16,777,216总像素约束，单帧最多4,194,304像素。两次画面不变只表示疑似底部/滚动未生效；无限加载、动画、复杂悬浮界面、重复纹理或过高顶栏可能需要缩小选区、手动或分段。受保护内容不绕过。输入检查与系统注入并非原子操作，请勿同时切换或操作其他窗口。
