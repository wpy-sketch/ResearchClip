# ResearchClip v4.2.7

Zotero标准批注现在支持持久待处理记录、手动同步与可配置只读自动刷新。关闭PDF或重启后可以继续处理本地修改，密钥不会随记录恢复。

- 六种同步状态区分已同步、本地待提交、远端变化、冲突、失败与只读。
- 版本条件写入前重新读取完整来源；冲突保留基线、本地和远端，提供明确选择。
- 固定新建key、逐项复读和删除确认避免重复创建或静默复活；断线和权限错误保留输入。
- 独立处理修订复用既有版本元数据，允许查看失败与冲突解决前的内容。
- 同步侧栏、按钮、缩放布局与四色图标调整；指南新增第33章和12项练习。

无新增第三方依赖。只同步Zotero标准批注，继续限制已验证写入类型；不改原PDF、不写Zotero数据库、不自动上传Markdown或私有手写。

升级采用schema19→20事务迁移和升级前验证快照，旧截图、Markdown与只读缓存保留。旧版应用不能写入schema20，请勿把旧程序指向已升级资料目录。

实际执行结果、人工验收边界与发布状态见[验收记录](qa/RELEASE-4.2.7.md)。真实授权弹窗和真实只读群组策略需人工验收，模拟HTTP边界不替代这些验收。
