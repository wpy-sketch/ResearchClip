# ResearchClip v4.1.3

现有Markdown编辑器新增固定格式工具栏与选区浮动栏：H1–H6、粗斜体/删除线/高亮、列表/任务/引用/分隔线、链接/素材图片/表格、代码和公式，支持查找替换、既有撤销重做与源码/预览。格式作用于当前光标或选区，恢复焦点和光标；Ctrl+B/I/K限定在Markdown，组合输入期间不触发。

图文模式直接编辑原文本块或图片注释，不重建文件读写和分栏系统。图片仍在上、注释在下；.md与assets继续使用原保存服务。未打开Markdown不显示空分栏。改善窄窗放大边界，格式栏可横向滚动；指南21章127示例33图、9条任务路线。

新增依赖remark-gfm4.0.1及其许可，用于安全表格/任务/删除线预览；高亮为ResearchClip扩展。SQLite保持12，无新迁移/Agent权限/上传流程。PDF、代码和Agent大型业务仍未接入；不包含Markdown导出PDF或独立资料备份/恢复。

Windows实际检查、未通过/未验证项见[工具栏验收](qa/MARKDOWN_TOOLS_4.1.3.md)与[发布检查](qa/RELEASE-4.1.3.md)。复杂嵌套格式状态采用保守识别，物理中文输入法与多DPI须人工核对。历史附件交付方式见[组件清单](RELEASE-COMPONENTS.md)；旧版本附件不代表旧运行时已在本轮重新安装验证。

本版共243个附件，覆盖此前32个正式版本的463个原附件：保留223个历史分卷和前版235个无冲突附件；v4.1.2的SOURCE/SHA按原名原字节放入Metadata.zip。逐项定位见V413-HISTORY-INVENTORY.json。工作流先校验精确内容再补传，不改变历史Release或标签。
