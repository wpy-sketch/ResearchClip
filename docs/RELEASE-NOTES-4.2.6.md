# v4.2.6 Zotero标准批注受控写入

本版在已完成的v4.2.5只读适配器上增量增加写入，不修改原PDF。实测Zotero10.0.6的官方Local API支持高亮、下划线和普通文字便签（note）；未验证的客户端版本及text/image/ink写入禁用。

先检测能力，再在Zotero中主动授权。选中PDF文字或便签区域准备草稿，检查评论、颜色与来源后提交。修改/删除使用对象版本条件，保存后复读确认；权限不足和版本冲突保留草稿。响应丢失时只复核原key，不盲目重复提交。密钥仅保存在Rust会话内。

批注面板按钮分组、圆角和窄窗口换行优化；关闭含草稿的PDF有专门提示。指南新增第32章与12项操作练习。图标更新为文档、摘录和关联符号，采用蓝绿黄红四色。

限制：本版草稿与待核实意图仅保留于PDF会话内，关闭前须处理或明确放弃；Zotero云端同步仍由Zotero负责。真实授权弹窗、真实群组只读权限、物理高DPI/多屏人工验收见[验收报告](qa/RELEASE-4.2.6.md)，不将Mock界面视为真实Zotero授权成功。后续双向同步另按Step16实施。

附件继承此前45个Release的4090项原附件；最终数量与匿名下载结果以正式发布回执为准。当前安装器及EXE是v4.2.6，历史版本附件保持原字节。没有增加PDF导出、私有笔迹转换或独立备份恢复系统。
