### 升级动作

1. 隔离数据库建立v1、v3、v5、v8、v10、v11及未来版本夹具，覆盖中文/emoji路径、全部现有资源与故障数据，不触碰真实AppData。
2. 记录旧ID、记录数量、精确annotation/Markdown内容、原图hash和关联；使用现有迁移器进行升级前quick_check/结构校验/一致快照。
3. 每个迁移在独立IMMEDIATE事务中执行，验证后更新user_version；失败回滚当前版本。多步升级已提交的中间版本须可安全重试。
4. 升级后验证外键、旧读写和重启、资源查询、失效/缺失提示、并发revision拒绝。迁移失败不能删库、修空坏JSON或改原图。
5. 真实用户升级方案：用户保存退出，安装已通过隔离验证的新应用，由正常打开路径创建并验证安全快照后迁移；未知未来版本拒写。未获额外授权，不在开发机器启动生产资料根验证。
6. 回退是关闭新模块/保留新库，或经明确授权使用验证过的升级前副本在新位置运行兼容版本；不自动用旧快照覆盖唯一库，不开发独立恢复UI。

## 3. 数据保护与回归策略

保留原图和PDF不可变、唯一目标禁止覆盖、既有Markdown单一文件保存与外部变化检查；文件先验证落盘再事务激活，失败只留受管未激活文件，不扫描删除未知文件。库删除行为保持显式确认，不能在资源孤立检查中自动删资料。

| 回归组 | 自动化要求 | 必须另行人工/原生验证 |
| --- | --- | --- |
| 原有截图 | 物理像素/裁切/取消/会话边界、Rust捕获探针 | Windows100/125/150/200%DPI、混合双屏、HDR/SDR、热键冲突 |
| 标注/原图 | geometry/history/serialization/导出像素、历史CAS、原图hash | Windows真实画布/文件对话框/贴图/退出 |
| Markdown | 源文/blocks/公式/模板/链接、外部冲突、多session不串写 | 中文IME、窄窗/拖动、光标插图、Ctrl+S/Z、关闭/重启 |
| 存储/资源 | 全迁移路径/故障回滚/未来版本拒写、SQL转义、关联/失效/文件一致性 | 升级独立旧资料副本，不改唯一资料 |
| Zotero | 版本握手、消息校验、并发/重试模型 | 隔离Zotero真实profile写回/重读；测试库而非用户主库 |
| PDF/私有ink | 坐标往返、hash失效、边界/坏格式、笔画撤销 | 真PDF复杂页面及HarmonyOS真机压感；模拟点不算真机通过 |
| 代码/Agent | 路径越界/链接替换/基准hash、Diff、拒绝/过期批准/取消 | Windows真实隔离、越界文件/网络拒绝、供应商版本行为 |
| 同步/剪藏/搜索 | 既有受影响测试、旧协议不扩大、无脚本执行 | 服务商真实认证/并发、浏览器工具栏/Host，不用本地Mock代替 |

检查执行按AGENTS影响范围：前端check；Rust格式/测试/Clippy；IPC/原生加Windows构建与对应硬件；依赖变化才做隔离干净安装。本轮未改依赖，不为“基线”删除现有node_modules重装。

## 4. 模块共用验收规则

每个模块必须给出：输入/输出版本、依赖模块/运行时、允许读写资源范围、正常/边界/失败/取消测试、性能预算、人工验收环境、回退状态和已知缺口。大文件、长任务、协议不支持、模型失败、权限拒绝不得静默成功。所有外部文献、网页、OCR、AI输出均是不可信数据，不转成终端指令。

性能目标必须在后续固定夹具上测p50/p95、峰值RSS/句柄/任务数并记录机器，不把目标当结果；大PDF缓存、多文档、2000图片向量、长笔迹、Agent长会话分别测量。现有大chunk警告与长期退出告警不由本规划消除。
