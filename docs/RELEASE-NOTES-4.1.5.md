# ResearchClip v4.1.5

Markdown新增可视网格表格与单元格编辑、行列增删、列对齐和Tab导航；确认时只改当前表格，支持撤销，保留其他公式、未知语法与换行。过时编辑会显示错误并保留新稿。

图片继续复用原拖入与素材库服务，支持alt/title和整个图文组复制、移动、删除。普通稿使用标准Markdown标题属性，旧图文稿的可见图题保存在原caption，保持私有version1。相对assets和原图不变；图片尺寸/预览比例不写非标准属性。空笔记插图自动建立“注释：”区域，也适用于已入库PDF截图的共同插入路径。

围栏代码可选语言、安全高亮、复制、行号及长代码折叠。语言操作仅改info首token，显示选项不写正文。新增lowlight3.3.0与highlight.js11.11.2及MIT/BSD许可；未知或超过32Ki字符的代码明示纯文本回退。复制沿用受限桌面剪贴板，Windows可能转换为CRLF，字符保持。

最近6项成功格式，Ctrl+Shift+T/I快速插表/插图；组合输入及与截图配置/实际注册冲突时不触发。延续四种保真视图、原撤销/保存/关闭与动态工作区，SQLite12，无新权限。指南23章141示例35图、11条路线。

实际结果与限制见[Step06验收](qa/MARKDOWN_STEP06.md)和[发布检查](qa/RELEASE-4.1.5.md)。真实系统OLE拖放因锁屏前台保护未通过，受控WebView文件导入及原生保存路径已通过；物理IME/多DPI仍需人工核对。原生PDF阅读器与带PDF位置的选区截图命令仍不可用；没有Markdown导出PDF或独立数据备份/恢复产品。

本版255附件完整继承此前34版955个原附件：223历史分卷与前版247个无冲突附件直接提供，v4.1.4的SOURCE/SHA保留在对应Metadata.zip。V415-HISTORY-INVENTORY.json逐项定位，所有原名/字节保留，不改旧Release/标签。见[下载说明](RELEASE-COMPONENTS.md)。
