# ResearchClip v3.1.2 · 本地相似图片检索

Windows x64 正式版本。新增原图完全重复与视觉接近检索，索引由用户主动启动；不自动合并或删除资料。

## 新增

- 素材页「相似与重复」与卡片「查找相似图片」；完全重复分组、25项结果分页、缩略图、尺寸、可调整pHash和颜色阈值，复用双图对比与知识卡片。
- SQLite schema7派生特征索引；迁移前备份、逐张计算、取消、复用、重建及损坏图片隔离。原图、笔记、标注和既有版本历史不改写。
- 可选本地Qwen3.5 4B图片对比辅助；完整离线包随附量化模型、视觉投影、固定CPU运行时和许可证。模型输出需要人工核对，不执行建议。
- 深浅色统一的结果面板、响应式卡片和进度状态；指南第4.4节补充逐步操作、实际测试界面图及流程示意。

## 下载与离线模型

轻量EXE/NSIS可独立使用传统检索。需要Qwen时，同时下载全部25个 `ResearchClip-v3.1.2-offline.zip.001` 至 `.025` 分卷和 `Assemble-Offline.ps1` 到同一空目录，以PowerShell运行脚本；脚本先核对分卷和完整ZIP的SHA256，再解压到新目录，不覆盖现有目录。完整离线包包含应用、安装包和约3.46GB模型/运行时。GitHub每附件2GiB限制，且大请求在本次传输中遇到连接重置，因此每卷至多128MiB；同一ZIP内容不变，不声称小型NSIS本身包含模型。

解压后直接运行目录内EXE可发现旁边的`similarity-ai`；安装版在「离线Qwen辅助」中选择该文件夹。无需下载、Ollama、云服务或本地HTTP服务器。首次校验较慢，请等待完成。首次安装WebView2仍可能需要微软运行时。

兼容的 **WebClipper v1.0.2** 扩展附件与原扩展ID保留；仍可在Chrome/Edge开发者模式解压加载。可选MathOCR安装材料保留，其Python/模型与本次Qwen包独立。

## 验收与限制

实际命令、失败及重跑结果见[本轮验收](qa/RELEASE-3.1.2.md)，使用方式见[完整指南](USER_GUIDE.md)，算法、资源限制、许可证来源见[相似图片设计](SIMILARITY.md)。

SHA比较受管PNG字节；同像素不同编码未必完全重复。感知距离不是概率或科研等价判断，小文字及公式差异可能漏检；相同原图也可能有不同笔记/标注。Qwen是可选实验性CPU辅助，输出可能幻觉、遗漏或截断，256token预算、180秒超时、12GiB进程预算，非全库语义搜索。

Windows x64为本次目标；macOS、全物理高DPI/多屏和第三方应用矩阵未执行。真实坚果云认证仍受凭据条件限制。旧版托盘/退出与未签名等已知限制保留；正式Release标识不意味着未执行项目通过。不新增PDF导出或独立全库备份功能。
