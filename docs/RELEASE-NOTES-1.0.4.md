# ResearchClip v1.0.4 · 本地公式图片转LaTeX

新增截图预览、知识卡片及编辑器「公式识别」：整图/框选、本地CPU推理、可编辑源码、安全KaTeX预览、复制，以及确认校对后插入Markdown或追加截图笔记。旧笔记、原图与标注不自动替换。

独立可选Python3.12运行时与固定ONNX模型，模型约171 MiB，仅用户确认后下载/离线导入；不自动安装、不上传图片。单任务、取消/超时、摘要/尺寸/输出限制与Windows Job Object，设置持久化。安装工具另附MathOCR-Setup ZIP，应用本身不含Python或权重，未配置不影响其他功能。

**必须人工校对**：实际模型会错认变量/上下标，曾把求和等号改为不等号、范数等号改为箭头。所有输出注明未验证，能预览不代表数学正确。不要将本版用于无人校对的科研公式录入。

实际143 Rust/320前端测试与真实ONNX流程、下载取消、模型负例、笔记/.md重开通过；新增Windows UI/剪贴板/系统对话框仍待人工验收。历史退出/托盘/卸载间歇问题保留，不因普通Release而关闭。
