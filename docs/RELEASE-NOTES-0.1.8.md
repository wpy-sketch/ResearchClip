# ResearchClip v0.1.8

此版本合并此前待交付的外部图片导入、双图对比以及列表/网格优化，发布为普通版本，不标记预发布。

## 新增与改进

- 顶部主动从Windows图片剪贴板导入，支持占用/无图片提示，不监视或上传内容。
- 将PNG/JPEG/WebP拖入素材库或打开的Markdown面板；批量导入、缩略图、改名、编辑及重启恢复复用现有资料系统。
- 双图对比独立工作区，可用素材或本地文件，提供并排、分割滑块、透明叠加、共享缩放/平移及A/B交换。
- 列表紧凑排列，网格保留清晰图片比例；调整深色容器、边框和操作分组。
- 应用内“使用指南”与[完整指南](USER_GUIDE.md)共用内容，覆盖截图、标注、素材、Markdown、OCR、贴图、设置、备份及错误处理。

## 使用

保存并退出旧实例后运行Windows x64 EXE，需要WebView2。导入限制：单图20 MiB/16,777,216像素，每批10图/64 MiB；坏图单独报错，有效图保留。重复导入建立副本；外部原图不修改。导入副本为RGBA8 PNG，不保证全部元数据或色彩配置，动画仅静态帧。

本地对比不入库，素材对比使用原图；不同尺寸以原像素左上角对齐，不自动配准。此工具不提供科学误差指标；可选差异图未实施。

实际命令、通过/失败历史及Windows人工清单见[0.1.8验收报告](qa/RELEASE-0.1.8.md)。自动化使用隔离数据，保留原始资料；不把测试图当作真实屏幕捕获证明。完整混合DPI、多屏、第三方剪贴板、长稳、Windows10和macOS未全面验证。历史退出句柄/托盘间歇问题仍跟踪。发布EXE未签名；本轮不附新的NSIS，不宣称安装/卸载复验。
