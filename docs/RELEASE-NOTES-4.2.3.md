# ResearchClip v4.2.3

PDF阅读器新增「截取文献内容」：框选当前页面，选择144/216/288 DPI，由PDF.js重新渲染选区。缩放和旋转后仍保存未旋转物理页面坐标；不截取应用工具栏或其他窗口，不修改原PDF。

截图关联稳定附件、内容SHA256、页码和矩形，可选择已有本地文献，复用素材库及原图不可变的图片标注工具。普通PDF允许来源留空，不猜测Zotero身份或编造DOI。取消渲染、保存阶段和失败均有明确状态。

一键插入当前Markdown光标，无文档时提示新建。图片上方、可编辑注释下方，稳定链接可以返回PDF原位置。分组标记让图片、公式/列表注释与来源链接一起拖动，撤销恢复原文；保存沿用相对assets，重开仍有效。新增隐藏面板滚动竞态修复及页码草稿失效保护。

PDF控件按可用宽度换行，最近摘录区域有界滚动；应用图标重新设计为叠页与裁切符号，使用蓝、绿、琥珀、珊瑚四色。离线指南29章、205项练习、57幅本地图示，新增完整摘录操作及四张Windows原生运行截图。

SQLite版本化迁移16→17只扩展既有截图写入意图和统一资源关系；001–016迁移不改。升级前沿用一致快照、校验和事务，未来版本拒写；旧程序不能写入升级后的数据库。无新增或升级依赖。详见[设计](architecture/PDF_EXCERPTS_STEP12.md)、[实际验收与人工步骤](qa/RELEASE-4.2.3.md)、[使用指南第29章](USER_GUIDE.md)及[下载组件与历史附件](RELEASE-COMPONENTS.md)。

本版继承此前42个Release的3163项原附件，保持原字节与历史分卷；303个最终附件包括当前程序、指南和原有伴侣组件。安装器未签名，外部可选运行时/模型仍按原组件说明配置。最终公开下载和历史完整性结果以发布回执为准。

物理多显示器DPI、真实Zotero窗口设置及双击文献链路仍需人工验收；模拟DPR不代表物理硬件通过。此前v4.2.2较长核对区间发现两项来源未明新增资料，原FAIL及文件保留，未自动清理或恢复；本版独立核对结果见验收记录。没有标准PDF批注写回、Markdown导出PDF或独立数据备份/恢复产品。本轮完成后停止。
