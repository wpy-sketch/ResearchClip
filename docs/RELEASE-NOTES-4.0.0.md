# ResearchClip v4.0.0

本版完成A13之后的独立验收批次，保留截图、标注、OCR、素材库、Markdown动态分栏、历史、文献、双向链接、锚点、工作流和离线语义检索。

- 修复语义任务轮询响应乱序导致界面状态回退，保留取消、完成和新查询的正确状态。
- Markdown文件失败提示包含操作和系统错误码；增加连续100次保存及Windows文件占用失败/重试测试。既有偶发I/O与退出告警尚未定位根因，未宣称根治。
- 编辑器保留至少240px画布并支持外层滚动，改善短窗口中图片被挤得难以拖动的问题。
- 指南增加六条任务阅读路线，保持18章114项练习31图；正文、目录随基础字号缩放，改进圆角、背景、窄窗与短窗布局。
- 新增[高级功能验收报告](qa/ADVANCED_FEATURE_REPORT.md)，分别记录实际PASS、失败、受阻和未运行项，附Windows人工验收清单。

没有新增依赖或数据库迁移，schema保持11，原图不变。离线语义检索是CPU实验功能，既有六类样本12查询Top1仅8/12；模型需确认下载或自行导入。物理高DPI/多屏、第三方WebDAV及GPU等边界见报告。

本版配套附件保留浏览器插件、MathOCR、完整离线指南及原有Qwen大模型资源索引。实际构建、安装器和GitHub发布回执见[发布验收](qa/RELEASE-4.0.0.md)。
