# ResearchClip v0.1.3

2026-10-17，Windows x64。按用户要求作为普通 Release 发布，不标记预发布。下载后请保存并退出旧实例；EXE 未签名，需要 WebView2。本次不提供新的 NSIS 安装包。

- 截图完成区和图片编辑器新增“识别文字”，使用 Windows 原生 OCR，本地处理、不上传图片、不附带或自动下载模型。
- 支持整图或图片内拖动框选；编辑器使用已有原分辨率标注合成图，原图和 SQLite 资料不变。
- 结果可手动修改、复制到系统剪贴板，或明确确认后插入当前 Markdown 光标位置。图文编排模式在末尾新增文本块。
- 保留行结构，以明显垂直间距推断段落；清理中文字符之间的引擎分词空格，保留英文词间距。
- 显示本机可用 OCR 语言和尺寸上限；处理空白图、语言缺失、无效选区、识别与剪贴板失败，串行门控防止重复任务积压。

本机仅安装简体中文 OCR 包，真实测试中能识别中文及部分英文/混合内容；英文存在错字，未验证独立英文引擎。低分辨率小字和特殊符号误差显著，复杂数学公式、上下标、表格、分栏阅读顺序与 LaTeX 不保证准确。识别文字不会自动写入笔记；请对照原图校对后再复制或插入。

语言依赖 Windows 的 OCR 可选组件；缺少所需语言时，由用户在 Windows 语言选项中安装，系统安装可能需要联网或管理员策略授权。应用不会替用户修改系统组件。macOS OCR 尚未实现。

实际命令、失败修复记录、自动化/原生测试及人工清单见 [0.1.3 验收](qa/RELEASE-0.1.3.md)。完整 DPI/多屏、真实屏幕捕获硬件矩阵、长稳、全新机器安装及历史退出/托盘问题仍保留，非预发布标记不代表这些未运行项目已通过。
