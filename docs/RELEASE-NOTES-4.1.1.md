# ResearchClip v4.1.1

Step02将既有左右分栏扩展为科研工作区：独立Markdown与图片标签、双向拆分、拖动调比例、隐藏/重开和分项目布局。未打开Markdown时保持无空白文档分栏。退出和关闭检查所有工作区草稿；同一文档重复打开聚焦已有会话。

界面增加12–20px字号按钮，窄/短面板滚动与指南容器布局；离线指南新增第19章、工作区阅读路线及4个操作示例。SQLite保持schema12，原始截图和已有Markdown服务沿用。

PDF、代码编辑器仅注册类型，底部终端仅布局区域，尚无运行后端。最多同时3份Markdown；布局不保存未保存正文或文件权限，重启需明确重新打开资源。没有Markdown导出PDF或独立备份/恢复系统。

实际检查及未验证项见[工作区验收](qa/WORKSPACE_STEP02.md)与[发布记录](qa/RELEASE-4.1.1.md)，设计见[工作台架构](architecture/WORKSPACE_SYSTEM.md)，操作见[使用指南](USER_GUIDE.md)。旧可选组件仍使用此前发布附件，v4.1.2按用户要求集中归档历史附件。
