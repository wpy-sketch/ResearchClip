# v4.2.2：混合页面适应与取消稳定性

本轮继续检查现有PDF/Zotero和布局，只修复实际复现的问题并发布补丁，不进入Step12。无新增依赖，SQLite保持16，不改001–016，不迁移或重置资料。

原生基线在588px阅读视口复现：当前窄页比例套给所有页面，20000pt海报页变27400px，文档横向范围27432px。页面变化又触发整体比例和恢复滚动。修复为适应模式逐页计算，列宽减去固定CSS间隙；适应布局固定在视口宽度，自定义缩放仍保持统一PDF比例及水平滚动。被动换页不再作为恢复布局的触发条件。

移除适应比例10%下限，支持已允许的较大页面在窄面板真正适应；小于1%有清楚标签。自定义仍25%–400%，达到下限时禁用缩小，防止在极小适应比例点“缩小”却变大。双页被动定位按行选择，保留同一行内显式选定页，不总是改为右页。

Zotero连接与来源查询取消后的结果必须失效，即使原生任务刚完成、响应仍在WebView桥上等待，也不能覆盖取消提示或重新显示候选。继续复用既有取消IPC和客户端，不增加API写入、权限或任意URL。

新增几何/页码/比例单元测试、混合页Windows回归，以及对生产组件实际复用请求状态对象的延迟Promise取消/替换/卸载测试。Tauri原生invoke桥只读且不可重定义，不使用替换桥的方法制造延迟；Windows测试实际HTTP取消。旧授权回归中未捕获令牌的问题改为显式打开有效授权、成功读取、关闭后再验证拒绝。真实Zotero点击按用户此前选择保留人工验收；不重试窗口操作。全部首/次进程均限定隔离目录，前后只读核对默认资料摘要。发布继承41版2866原附件，目标297附件。
