# ResearchClip v4.2.2

修复混合尺寸PDF阅读布局：竖版、横版和大海报页分别适应所在列，滚动换页不再改变整篇页面尺寸或跳回旧位置。双页固定间距正确计入可用宽度，同一行内保留明确选中的页。极大页面支持小于10%的适应比例，小于1%有清楚提示，缩小按钮不再反而放大页面。自定义缩放仍为25%–400%。沿用v4.2.1按实际显示密度绘制的清晰图块与缓存预算，不改原PDF。

修复Zotero连接测试和来源查询的取消竞态：取消后晚到的旧响应失效，不能覆盖取消提示或显示过期候选；旧任务也不能清除新任务的加载状态。复用现有只读API及取消IPC，不写Zotero数据库。真实Zotero设置/双击附件操作继续按用户选择保留人工验收。

指南维持顺序编号的28章，增加混合页面及取消核对练习，共193项练习、53幅离线图片。新增两幅真实Windows隔离练习界面。无新增依赖，SQLite保持16，001–016迁移不变。安装器未签名。

资料核对边界：较早长区间的23个既有文件摘要保持，但发现2个新增文件，来源尚未确认；失败记录及文件均保留，未自动清理或恢复。安装/卸载区间25文件摘要保持。详见验收记录中的分区间结果，不能称整个开发期间资料完全无变化。

本版发布目标297附件，完整继承此前41版2866项原附件，原223运输分卷不重压缩。详见[设计](architecture/PDF_STABILITY_422.md)、[验收](qa/RELEASE-4.2.2.md)及[组件说明](RELEASE-COMPONENTS.md)。本轮不进入Step12，不包含Markdown导出PDF或独立数据备份/恢复系统。
