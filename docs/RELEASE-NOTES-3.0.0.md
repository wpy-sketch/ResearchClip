# ResearchClip v3.0.0

Windows x64正式版本；保留兼容的浏览器剪藏插件v1.0.2。**正式标识不代表所有服务商、Windows硬件或macOS已经验收。**

## 新增与改进

- 手动WebDAV资源级双向同步：选项目/未分类，原图、标注JSON与全部历史、笔记/OCR、标签、项目、标准Markdown与受管相对PNG。每台设备独立数据库，不上传SQLite。
- 强ETag、If-Match/If-None-Match、并发探针；失败拒绝写入。不可变SHA256对象、持久待确认队列、断线后手动恢复、逐项本地/远端/双副本冲突确认。远端删除不自动应用。
- Windows Credential Manager保存凭据；HTTPS证书验证开启，不跟随重定向。外部文档须系统对话框授权，接收文件使用新受管目录，原图与外部原文件保留。
- schema5→6事务迁移和升级前备份；显式标注当前head支持并发分支，不改变普通撤销重做。
- 设置分类导航、深浅主题表单和窄窗口适配；使用指南细化到三级/四级标题，21张离线图、操作顺序、完成检查和失败排错。

## 使用

下载EXE或NSIS，先保存并退出旧实例。安装需要WebView2，未签名产物请核对SHA256。浏览器插件包保持原ID和Native Messaging流程，按[安装说明](../browser-extension/README.md)加载。可选MathOCR脚本保留，不附带Python或模型。

WebDAV按[完整指南](USER_GUIDE.md)第13.1节配置、测试、授权及同步。**指定坚果云ResearchClip目录尚未完成账号认证验收**；隔离测试不能证明其兼容。不满足安全条件的服务器会被拒绝。首次请用专用小项目，不输入/公开聊天中的密码。

## 限制与验收边界

当前Windows优先，手动同步，无定时同步；单blob64MiB、最多5000资源、历史1024条/16MiB，不截断历史。Markdown同步仅支持应用生成的受管PNG assets，其他本地引用明确拒绝；共享标签名称差异需人工统一。停止等待当前请求，最多约30秒。缓存、历史及探针不自动删除，需预留空间。

默认WsgiDAV配置实际未通过安全探针；隔离参考配置明确增加内容ETag和原子条件提交才用于一致性测试。坚果云认证验收、物理双设备、完整DPI/多屏/macOS尚未通过本轮验收。历史QA-001/002/008和公式误识别风险保留。详见[实际检查、初次失败与人工清单](qa/RELEASE-3.0.0.md)。
