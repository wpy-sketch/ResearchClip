# A08 本地相似图片检索

## 1. 范围与入口

素材页「相似与重复」浏览完全重复组；每张卡片的「查找相似图片」按钮按整库特征检索。索引只在用户点击更新/重建时执行，不监听剪贴板、不启动自动扫描、不合并或删除资料。结果可进入既有知识卡片和双图对比。标注和笔记与原图分离，因此原图重复不等于知识卡片可以删除。

## 2. 算法评估与选择

| 算法 | 用途 | 局限 |
| --- | --- | --- |
| SHA-256 | 原始受管PNG字节完全一致，文件名不参与 | 同像素不同PNG编码/元数据也可能不同；不是扁平化标注版本判定 |
| pHash | 32×32灰度低频DCT，8×8系数去DC后按中位数生成64位容器 | 对版式、文字、配色可漏检或误报，不是语义或科学等价判断 |
| dHash | 9×8灰度横向梯度64位，结果辅助显示 | 平色、近似布局可能碰撞，不单独用它判重复 |
| 缩放后感知比较 | 16×16 RGB平均绝对差，0–255，过滤平色哈希碰撞 | 会忽略小文字/局部差异；网格归一化可能扭曲不同宽高比 |

复用既有有界PNG解码及保持比例的缩略采样逻辑。透明像素先在白底合成再生成特征；不更改原图透明度或输出。默认视觉筛选pHash距离≤10/64且平均颜色距离≤35/255，可分别调整；完全重复独立于阈值。dHash仅作为补充指标展示。距离不显示为百分比或经校准概率。原图和可编辑标注不会被渲染覆盖。

## 3. 数据与迁移

SQLite schema6→7使用新增`007_image_features.sql`，沿用升级前一致性快照、事务迁移、未知未来版本拒绝和回滚。既有001–006迁移不改写。`image_features`包含screenshotId、contentHash、perceptualHash、differenceHash、768字节descriptor、hashAlgorithmVersion=1、sourceStamp、status/error与updatedAt，外键删除随截图记录级联。

原图路径、尺寸发生变动时触发器使该条索引失效；扫描比较路径、尺寸、文件长度与修改时间，未变化的记录复用，人工纠错笔记/标题/标注变化不会重新计算不可变原图。查询核对参考图及候选文件戳，跳过过期或不可访问项。外部强行改写原图并同时伪造长度/修改时间不在不可变工作区契约内，可显式重建复核。

索引是可重建派生数据，**不加入WebDAV同步载荷**，不上传SQLite，不和OCR正文/笔记混存。取消不清空已经成功提交的索引；损坏图片记录失败并保留原素材。

## 4. 任务、性能与权限

- 单后台线程，每次至多一张PNG及解码帧，沿用约1677万像素/有界PNG预算；处理后释放图像，只保存小特征。
- keyset游标扫描固定上界，一批最多10万张，超限明确拒绝；新增图片由下一次更新处理，重启保留已完成索引且不自动继续。
- 查询流式遍历特征，不加载所有原图；每页25项、最多前5000项可翻页。重复组由SHA索引SQL聚合，每页20组。条件过宽时缩小阈值再比较。
- 只增加main窗口的业务命令。WebView不接受任意文件路径/SQL，不增加通用fs、shell或网络访问权限。
- 关闭面板保留后台任务，可重新打开取消；真正退出先请求取消并等资源回收。前端按会话generation丢弃过期查询并清理轮询/缩略图ObjectURL。

## 5. Qwen3.5 4B离线辅助

按用户要求随完整离线发布包提供模型及CPU运行时；传统索引不依赖模型。采用[Qwen官方模型](https://huggingface.co/Qwen/Qwen3.5-4B)的[Unsloth固定GGUF量化](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF/tree/e87f176479d0855a907a41277aca2f8ee7a09523)：Q4_K_M 2,740,937,888字节及F16视觉投影672,423,616字节，Apache-2.0；[llama.cpp b11748 Windows CPU运行时](https://github.com/ggml-org/llama.cpp/releases/tag/b11748)，主代码MIT、随附OpenMP按其许可证分发。

安装/推理不调用云端、Ollama或通用本地HTTP服务。`SimilarityAi`通过受限文件夹对话框接受离线包路径；固定构建清单核对大小与SHA256，拒绝额外DLL/EXE/模型插件及网络共享目录。校验通过且文件戳不变才复用校验缓存。运行时独立子进程，私有临时缩略图、固定命令参数、清理继承配置、`--offline`、4 CPU线程、2048上下文、256生成token、180秒、12GiB Windows Job上限，取消/父退出杀进程并等待回收。模型输出只能作为有界纯文本显示，不能执行、自动写笔记或触发删除；结果绑定准确的A/B图片ID，切换图片不串用旧建议。

实际核对了安装版本`--help`与[上游多模态入口](https://github.com/ggml-org/llama.cpp/blob/b11748/tools/mtmd/mtmd-cli.cpp)。该工具标注实验性；重复`--image`会只用最后一张，故使用受管临时目录中的相对列表`a.png,b.png`，避免路径逗号问题；verbosity=0保留输出，不用会连文本一起关闭的log-disable。

**局限**：模型可能在256token预算内只输出部分分析、漏掉细微公式/文字或产生幻觉。它只辅助比较当前两张原图缩略图，不做全库向量搜索，不输出校准相似概率，不证明数学正确性。Windows x64 CPU是本次目标，其他硬件和macOS需单独验证。

## 6. 完整离线包

[GitHub每附件限制2GiB](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)，故完整离线包分卷发布，包含桌面程序、NSIS、模型、视觉投影、运行时和许可证。所有卷及组装脚本放同目录后，校验并组装解压。可直接运行解压目录的EXE，自动发现旁边`similarity-ai`；也可运行其中NSIS安装主体，再在相似面板选择解压目录中的模型文件夹。**小型NSIS本身不内嵌数GB模型**；完整离线套件提供所有资源，不在首次推理时偷偷下载。模型不进入Git源码，首次使用不联网。
