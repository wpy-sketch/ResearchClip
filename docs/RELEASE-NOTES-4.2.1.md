# ResearchClip v4.2.1

修复PDF高倍与高DPI显示模糊：可见区域按实际物理密度渲染，离开后释放图块，支持范围内的扫描图不再因较低图像阈值重采样。原PDF和受管副本字节保持，不修改页结构；单会话/全局缓存继续有预算。高倍250%及模拟DPR2下，720万像素无损练习图已与独立源像素比较，源文件不重新压缩。低清原扫描、超过解码保护预算的图片无法凭空恢复细节。

设置及PDF来源侧栏新增Zotero配置助手：复制当前researchclip.exe路径，说明自定义外部阅读器、本机API授权和只读无需API key，独立测试连接/取消并显示API/schema，点击打开指南第28章。复用现有只读客户端及稳定来源存储，不写Zotero数据库，不引入任意远程URL或云密钥入口。

工作台按面板宽度、字体与界面缩放自然重排；窄面板导航转到页面上方，工具条换行，主导航收为图标轨道。没有Markdown时仍无空白分栏，原编辑器、草稿与撤销不重建。原创图标重设计为四色论文页与回形夹；指南28章、191项练习、51幅离线图片，含4幅新增真实应用练习界面。

没有新增应用依赖；SQLite保持16，001–016迁移不改。目标291附件，完整继承此前40版2575项原附件；原223运输卷不重压缩，同名校验文件以版本Metadata.zip保存。安装器未签名。[设计](architecture/PDF_QUALITY_ZOTERO_421.md)与[实际测试/已知限制](qa/RELEASE-4.2.1.md)记录测试环境和人工边界。没有Markdown导出PDF或独立数据备份/恢复系统。
