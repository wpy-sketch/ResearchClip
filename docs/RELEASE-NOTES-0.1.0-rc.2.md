# ResearchClip v0.1.0-rc.2 · Windows 预发布

此次更新包含Markdown图文文档、动态分栏工作区和文件重命名。程序内版本仍为0.1.0；此次为预发布，不表示完整正式版质量验收完成。

## 下载与运行

- ResearchClip-v0.1.0-rc.2-windows-x64.exe：最新Windows x64程序，含本轮Markdown更新。
- SHA256SUMS.txt：文件校验值。
- SOURCE.txt：源码提交和本次交付范围。

本次没有新NSIS安装包；rc.1安装器不包含本次更新。需要WebView2，程序未签名。先保存资料并彻底退出旧实例，再运行新EXE；单实例机制可能让第二次启动恢复旧窗口。程序仍使用本地应用资料目录，不是便携数据模式。请保留现有资料备份。

## 更新

1. 图文文档：多选素材，导入已保存标注的合成图与笔记快照；图片和对应注释整体排序，插入中间文本。
2. 动态分栏：未打开文档没有右侧面板，新建/打开后出现，关闭后恢复原工作区；分隔线可拖动并记住比例。
3. 空白Markdown：内存中新建untitled.md，支持中文/英文/LaTeX源码、普通Markdown语法、预览、撤销重做及Ctrl+S。
4. 图片联动：素材卡或当前图片编辑器的“插入到 Markdown”在右侧记住的光标处插入合成图，原图不改。
5. 保存与重开：标准UTF-8 .md和相对assets，首次/另存系统选择位置，继续保存检测外部修改；脏文档关闭提供保存/放弃/取消。
6. 命名：右键文件名重命名；未保存时修改首次保存建议名称，已保存时同目录安全改名，后续Ctrl+S使用新路径；不覆盖同名文件。
