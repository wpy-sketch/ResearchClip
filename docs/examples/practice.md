# 演练记录

> 这是虚构练习材料，不能用作科研结论或真实文献。

## 研究问题

如何把一张练习图片整理成可再次找到的记录？

## 方法

1. 自行准备一张非唯一副本的练习图，导入素材库。
2. 给它添加“演练”标签，画箭头并保存标注。
3. 在此处放置光标，从卡片插入图片，再保存到新的目录。

## 观察

- **待核对**：峰值发生在第3秒（虚构文字）。
- 公式输入练习：$x^2+y^2=r^2$。
- 文献引用练习：导入同目录的 references.bib，再由应用插入所选引用键。

## 知识连接

另建并保存“Apollonius Circle”练习文档，再输入两个左方括号，从候选中选择目标。
本示例不预置内部ID：ID由当前资料库登记，不能把其他电脑的ID当作本机目标。
