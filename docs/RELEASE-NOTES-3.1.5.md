# ResearchClip v3.1.5 · 双向链接与知识图谱

- 输入 `[[` 搜索已登记文档与截图，选中后插入稳定ID内部引用；预览点击跳转。
- 文档、卡片详情提供反向链接、来源行号与定位；应用内重命名保持目标，缺失内容保留失效提示。
- 后台增量索引与可取消的全部更新；摘要校验、事务替换，循环和自引不递归展开。
- 本机知识图谱支持不同形状节点、缩放、平移、点击打开、当前文档邻居、项目/标签筛选。
- 标准Markdown副本导出将可用文档目标转换为相对链接，无法转换的引用列出警告；不覆盖已有文件。
- 指南新增第16章，补全插入、反查、维护、导出、安全边界和任务目录；继续优化分栏及图谱的深浅色和窄窗口布局。

SQLite从schema8迁移至9，沿用迁移前安全快照和失败回滚。无新增第三方依赖。内部ID映射、引用索引与文档图谱标签当前仅本机，不随WebDAV同步；外部文件移动不自动跟踪。图谱上限1000节点、5000连线，不承诺大规模布局。文档链接的导出目标不会自动打包复制。

实际测试与未验证项见 [本版验收](qa/RELEASE-3.1.5.md)。操作见 [使用指南](USER_GUIDE.md)，数据契约见 [A10架构](INTERNAL-LINKS.md)。Windows需要WebView2，安装包未签名；macOS及完整物理DPI/多显示器矩阵须分别验证。不新增PDF或独立备份恢复系统。
