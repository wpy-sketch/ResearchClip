# ResearchClip v3.1.9

新增实验性离线图文语义搜索：主动建立索引后，可用中英文描述查找视觉相关截图。支持项目/收藏范围、取消、增量更新、重建及删除派生索引；普通搜索随时可用。模型下载需确认，图片不上传。

固定多语言CLIP配对，模型约228MB；仅CPU、2个推理线程，最多2000张。六类小样本12查询仅8条Top1正确，软件截图与追逃/流程图存在误匹配，须人工核对。安装和离线模型步骤附在指南包内的 `semantic-search` 目录。

素材库新增模式切换、响应式候选卡片和任务状态，指南按顺序编号，补充启用、取消、重启、删除及回退示例。保留旧版截图、标注、OCR、素材库、Markdown、双向链接、锚点与命令工作流。
