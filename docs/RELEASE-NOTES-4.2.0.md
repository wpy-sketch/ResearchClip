# ResearchClip v4.2.0

Step11增加Windows外部PDF打开：安装器注册“打开方式”候选，保留当前默认程序；Zotero可在常规设置选择researchclip.exe。路径作为独立参数接收，中文、空格和合法特殊字符可用；单实例交接，同内容聚焦已有标签。继承v4.1.9的PDF阅读器、独立Markdown和所有既有功能。

可选Zotero Local API只读来源：个人/群组范围、原件授权与摘要核对、元数据预览、用户确认后本地关联。复用已有文献稳定ID与资源模型，SQLite16事务迁移保留旧映射；同DOI保留原记录，来源快照标为待人工核对。API关闭、未启动、超时或无法匹配时普通PDF仍可阅读。不写Zotero数据库、不申请写入密钥、不修改PDF页结构。

来源侧栏适配窗口缩放与明暗主题，原创科研烧瓶图标调整蓝绿黄红色彩。指南28章、187项练习、47幅离线图片，新增外部阅读器设置、取消与离线回退说明。没有新增应用依赖。

正式发布目标285附件，继承此前39个版本2290项原附件的完整字节；旧223运输卷不重新压缩，历史同名SOURCE/SHA保存在版本Metadata.zip，逐项定位见V420-HISTORY-INVENTORY.json。发布状态见[发布检查](qa/RELEASE-4.2.0.md)。

边界：本机Zotero10.0.3及API v3/schema44只读探测已执行；实际Zotero设置→双击附件的UI验收受应用授权超时影响，仍需人工。原生应用与隔离HTTP服务测试分开记录。旧无实例标识接口、Zotero页码跳转、批注读取/写回、未下载附件尚不支持。安装器未签名。本轮一次误启动测试实例触及默认空资料库，已保留升级前快照及完整性核对，未做破坏性恢复；详见[Step11报告](qa/ZOTERO_PDF_STEP11.md)。

不包含Markdown导出PDF或独立备份/恢复系统，完成本阶段发布后停止。
